# Второй голос

Тренажёр для тех, кто учится петь в два голоса. Программа играет мелодию, показывает на нотной ленте вашу партию (второй голос) и через микрофон слушает, попадаете ли вы в ноты.

Работает в браузере на компьютере и на телефоне. Ничего устанавливать не нужно, звук синтезируется прямо на странице, запись голоса никуда не отправляется.

## Как открыть

**На компьютере.** Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` в Chrome, Edge или Firefox.

**На телефоне или по ссылке.** Включите GitHub Pages: Settings → Pages → Build and deployment → Source: *Deploy from a branch*, выберите ветку и папку `/ (root)`, нажмите Save. Через минуту программа будет доступна по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

Микрофон работает только на страницах с адресом `https://` и в файле, открытом на компьютере. Браузер спросит разрешение — нажмите «Разрешить».

## Как заниматься

1. **Послушать.** Выберите упражнение или песню и послушайте оба голоса. Фиолетовые ноты — ваша партия, серые — мелодия.
2. **Петь вместе.** Пойте второй голос вместе с громкой подсказкой. Сбавьте темп до 70–80 %, трудную фразу выберите в поле «Фрагмент» и включите «По кругу».
3. **Тихая подсказка.** Подсказка едва слышна. Включите микрофон: зелёная линия — вы в ноте, жёлтая — вы ушли на мелодию, красная — мимо.
4. **Самостоятельно.** Звучит только мелодия. После проигрыша программа покажет точность в процентах и самые трудные ноты.

Ещё есть:

- **Разминка на интервалы.** Программа задаёт тональность и играет ноту, вы поёте терцию, сексту, кварту или квинту от неё.
- **Мои песни.** Впишите мелодию своей песни — программа построит к ней второй голос (терцией ниже, секстой ниже, терцией выше или на тонике). Если партия второго голоса у вас уже есть, впишите и её.
- Транспонирование под ваш голос, темп, громкость каждого голоса, метроном, оценка «в любой октаве» (для мужских голосов).

Лучше заниматься в наушниках: тогда микрофон слышит только вас.

## Как записывать ноты

| Запись | Что значит |
| --- | --- |
| `до ре ми фа соль ля си` или `C D E F G A B` | ноты; `H` тоже означает си |
| `фа#`, `сиb`, `F#`, `Bb` | диез и бемоль, можно `♯` и `♭` |
| `до5`, `ля3` | октава: 4 — первая, 5 — вторая, 3 — малая; без цифры — первая |
| `до'`, `ля,` | на октаву выше или ниже первой |
| `ми:2`, `ре:0.5`, `до:1.5` | длительность в долях (четвертях); без длительности — четверть |
| `п` или `R` | пауза, тоже с длительностью: `п:2` |
| `\|` | тактовая черта, только для удобства |

Пример: `до до соль соль | ля ля соль:2 | фа фа ми ми | ре ре до:2`

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html`, `css/style.css` | страница и оформление (светлая и тёмная тема) |
| `js/music.js` | разбор нотной записи, тональности, построение второго голоса |
| `js/pitch.js` | определение высоты голоса по микрофону (алгоритм YIN) |
| `js/audio.js` | синтезатор двух голосов и метроном (Web Audio) |
| `js/songs.js` | упражнения и песни |
| `js/app.js` | интерфейс: проигрывание, оценка, нотная лента, разминка, редактор |

Песни в библиотеке — народные или давно перешедшие в общественное достояние. Добавить свою в библиотеку можно в `js/songs.js` в том же формате.

Тесты (нужен Node.js 18+):

```
npm test
```
