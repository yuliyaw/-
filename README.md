# Второй голос

Домашний педагог по вокалу в браузере. Программа ведёт урок на каждый день, слушает вас через микрофон и подсказывает, что получается, а что нет:

- **Сегодня** — урок дня (дыхание → распевка → техника → сольфеджио → песня), самочувствие голоса, дневник и график занятий, ваш диапазон и тип голоса.
- **Распевка** — 8 упражнений (губная трель, мычание, сирена, ми-мэ-ма-мо-му, арпеджио, стаккато, октавный скачок, гамма на 9 нот). Фортепиано поднимает их по полутонам до верха вашего диапазона и опускает обратно; есть комплекс на 5 минут.
- **Дыхание и опора** — дыхание животом, долгий выдох «с-с-с» с секундомером, ровный долгий звук, толчки «ф» в ритм, филировка.
- **Техника EVT** — как устроен голос и что такое смыкание, все фигуры по Эстилл (начало и окончание звука, масса связок, ложные связки, щитовидный и перстневидный хрящи, гортань, мягкое нёбо, язык, твэнг, челюсть, губы, опора шеи и корпуса) и шесть качеств голоса (речь, фальцет, плач, твэнг, опера, белтинг). У каждой фигуры: объяснение простыми словами, анимированная схема, звук на модели голоса, «найдите у себя», проверка по микрофону и сравнение двух вариантов «А / Б».
- **Сольфеджио** — 23 урока: ноты, нотный стан (скрипичный и басовый ключ), ступени, мажор и минор, интервалы на слух и голосом, аккорды, ритм, пение с листа, диктант.
- **Второй голос** — песня, ваша партия на нотной ленте, четыре шага от «послушать» до «самостоятельно», оценка каждой ноты, подбор тональности под ваш голос.
- **Мои песни** — впишите мелодию (и, если есть, свой второй голос и текст) — программа построит партию.
- **Разбор вокала** — спойте или загрузите запись с диктофона: интонация, устойчивость, вибрато, смыкание связок, звонкость, атака, дыхание, динамика и советы, что тренировать.
- **Голос и здоровье**, **Как заниматься** — правила гигиены голоса и порядок занятий.
- **Спросить преподавателя** — появляется, когда программа открыта внутри Claude: можно задать вопрос о технике или о своём разборе.

Звук синтезируется прямо на странице, запись голоса никуда не отправляется. Дневник, диапазон, песни и разборы хранятся только в этом браузере.

Раздел EVT написан своими словами по мотивам метода Джо Эстилл и общей физиологии голоса. Это не официальный курс Estill Voice International. Программа не заменяет врача: при боли и осиплости — к ЛОР-фониатру.

## Как открыть

**На компьютере.** Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` в Chrome, Edge или Firefox.

**На телефоне или по ссылке.** Включите GitHub Pages: Settings → Pages → Build and deployment → Source: *Deploy from a branch*, выберите ветку и папку `/ (root)`, нажмите Save. Через минуту программа будет доступна по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

Микрофон работает только на страницах с адресом `https://` и в файле, открытом на компьютере. Браузер спросит разрешение — нажмите «Разрешить». Лучше заниматься в наушниках: тогда микрофон слышит только вас.

## Как записывать ноты (Мои песни)

| Запись | Что значит |
| --- | --- |
| `до ре ми фа соль ля си` или `C D E F G A B` | ноты; `H` тоже означает си |
| `фа#`, `сиb`, `F#`, `Bb` | диез и бемоль, можно `♯` и `♭` |
| `до5`, `ля3` | октава: 4 — первая, 5 — вторая, 3 — малая; без цифры — первая |
| `до'`, `ля,` | на октаву выше или ниже первой |
| `ми:2`, `ре:0.5`, `до:1.5` | длительность в долях (четвертях); без длительности — четверть |
| `п` или `R` | пауза, тоже с длительностью: `п:2` |
| `\|` | тактовая черта, только для удобства |

Пример: `до до соль соль | ля ля соль:2 | фа фа ми ми | ре ре до:2`

Текст песни пишется слогами через пробел, по слогу на ноту мелодии: `Ти- хо, ти- хо, звёз- доч- ка`. Дефис в конце слога — слово продолжается, `_` — нота без нового слога.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html`, `css/style.css` | страница и оформление (светлая и тёмная тема, телефон) |
| `js/music.js` | нотная запись, тональности, построение второго голоса |
| `js/pitch.js` | определение высоты голоса (алгоритм YIN) |
| `js/voice.js` | анализ голоса: спектр, смыкание (H1–H2), звонкость, вибрато, атака, отчёт по записи |
| `js/audio.js` | синтезатор голосов, фортепиано, метроном, модель голоса для демонстраций |
| `js/core.js` | ядро: разделы, микрофон, нотная лента, проигрыватель, табло, клавиатура, дневник |
| `js/home.js` | «Сегодня» и замер диапазона |
| `js/warmup.js` | распевка и дыхание |
| `js/evt-content.js`, `js/evt.js` | уроки EVT, схемы, шкалы, сравнение «А / Б» |
| `js/solfege.js` | курс сольфеджио и нотный стан |
| `js/harmony.js`, `js/songs.js` | второй голос, песни, редактор |
| `js/analysis.js` | разбор вокала |
| `js/teacher.js` | «Спросить преподавателя» |

Тесты (нужен Node.js 18+):

```
npm test
```
